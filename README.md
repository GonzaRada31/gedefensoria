# Sistema de Gestión de Actuaciones - Defensoría del Pueblo de Jujuy

## Descripción
Este proyecto tiene como objetivo modernizar y digitalizar la gestión de actuaciones y expedientes de la Defensoría del Pueblo de la Provincia de Jujuy.

## Objetivos del Proyecto
- Centralizar la recepción de denuncias y actuaciones.
- Proveer trazabilidad total sobre el estado de cada trámite.
- Facilitar la comunicación con el ciudadano.
- Implementar prácticas modernas de DevOps para asegurar alta disponibilidad y despliegues continuos.
